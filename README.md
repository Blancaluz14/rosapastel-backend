\# Sistema de Gestión de Ventas - Heladería Rosa Pastel



\## Descripción

Backend del sistema de gestión de ventas para la Heladería Rosa Pastel, desarrollado con Spring Boot y MySQL.



\## Tecnologías utilizadas

\- Java 25

\- Spring Boot

\- Spring Data JPA

\- MySQL

\- Maven

\- API REST



\## Funcionalidades implementadas



\### Gestión de categorías

\- Registrar categorías.

\- Consultar todas las categorías.

\- Consultar categorías por ID.

\- Actualizar categorías.

\- Eliminar categorías.



\### Gestión de productos

\- Registrar productos.

\- Consultar todos los productos.

\- Consultar productos por ID.

\- Actualizar productos.

\- Eliminar productos.



\## Validaciones

Se implementaron validaciones de datos y un manejador global de excepciones para responder ante errores en las solicitudes.



\## Base de datos

\- Motor: MySQL.

\- Base de datos: heladeriarosapastel.



\## Ejecución del proyecto

1\. Clonar el repositorio.

2\. Crear la base de datos heladeriarosapastel.

3\. Configurar la conexión a MySQL en application.properties.

4\. Ejecutar el proyecto con Maven:



```bash

mvn spring-boot:run
